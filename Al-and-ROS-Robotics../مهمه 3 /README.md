
مهمه 3 : بناء مساعد صوتي Voice-to-Voice AI Assistant

فكرة المشروع :

مساعد صوتي ذكي يسمح للمستخدم بالتواصل مع الذكاء الاصطناعي عن طريق الميكروفون أو رفع ملف صوتي أو الكتابة

يعتمد المشروع على ثلاث مراحل:

🎤 Speech-to-Text → 🤖 LLM Processing → 🔊 Text-to-Speech

 طريقة العمل :

1. Speech-to-Text: تحويل صوت المستخدم إلى نص
2. LLM Processing: إرسال النص إلى Groq لمعالجته وتوليد الإجابة
3. Text-to-Speech: تحويل إجابة الذكاء الاصطناعي إلى صوت باستخدام "SpeechSynthesis" في المتصفح

عند رفع ملف صوتي، يتم استخراج النص منه، ثم يفهمه الذكاء الاصطناعي ويعرض الإجابة مكتوبة ويشغلها صوتيًا

ملفات المشروع:

- "index.html" — واجهة المساعد
- "app.js" — التحكم بالمايك والكتابة والملفات الصوتية والردود
- "ro.php" — الـBackend المسؤول عن التواصل مع Groq
- "config.php" — حفظ مفتاح Groq API

 التقنيات اللي استخدمتها :

HTML, CSS, JavaScript, PHP, Groq API, Speech-to-Text, Speech Synthesis, InfinityFree.



المشاكل اللي واجهتها :

اخذ تطوير المشروع وقتًا طويل بسبب كثرة التجارب والمشاكل، خصوصًا في تشغيل الميكروفون وربط الـAPI وإرفاق الملفات الصوتية

تم تجربة أكثر من خدمة ومفتاح API، من ضمنها Google Gemini ثم Groq، وتم تغيير المفاتيح أكثر من مرة أثناء اختبار الاتصال وحل المشاكل

كما تم تعديل طريقة التعامل مع الملفات الصوتية عدة مرات حتى أصبح بإمكان المشروع استقبال ملف صوتي وتحويله إلى نص ثم إرساله للذكاء الاصطناعي

ايضا تم تعديل الميكرفون اكثر مره بسبب الاكواد ومره بسبب موقع InfinityFree ومره من المتصفح 



ملاحظة

تم فهم متطلب Text-to-Speech على أنه تحويل إجابة الذكاء الاصطناعي إلى صوت ليسمعها المستخدم، لذلك تم استخدام "SpeechSynthesis" المدمج في المتصفح بدل إنشاء ملف صوتي مستقل
