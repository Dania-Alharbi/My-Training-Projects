مهمه 2: المطلوب نسوي صفحة ويب بسيطة تتعامل مع قاعدة البيانات 


​الوصف :
موقع ويب تفاعلي لإدارة بيانات المستخدمين (إضافة مستخدم جديد، عرض البيانات في جدول، وتغيير حالة المستخدم) مع الربط بقاعدة بيانات MySQL واستضافته على منصة InfinityFree




​هيكلية الملفات بتكون 4 ووظيفة كل كود:

 ه ​db.php: يحتوي على إعدادات الاتصال بقاعدة البيانات باستخدام مكتبة mysqli والتأكد من نجاح الاتصال
 
 ه ​insert.php: يستقبل البيانات المدخلة من النموذج (name, age, status) ويقوم بإدراجها كسطر جديد في جدول users
 
 ه ​toggle.php: يتعامل مع استعلام التحديث (UPDATE) لتغيير حالة المستخدم عكسيا بين مفعل (1) وغير مفعل (0) بناءً على الـ id
 
 ه ​index.php: الصفحة الرئيسية التي تجمع واجهة المستخدم (HTML/CSS)، وتعرض الجدول وتتصل بملف db.php لجلب البيانات الحالية





 






 
 
 

 
 
 
 
 المشاكل التي تمت مواجهتها وكيفية حلها :

المشكلة: ظهور خطأ عام (HTTP ERROR 500) بسبب خطأ مطبعي في حالة أحرف كلمة المرور بملف db.php

الحل : تم تفعيل إظهار أخطاء الـ PHP لتحديد المسبب بدقة بدلاً من (HTTP ERROR 500) عن طريق إضافة الكود التالي في بداية ملف db.php :


  php

  
  
  ini_set('display_errors', 1);
  
  error_reporting(E_ALL);

  بعدها رحت للصفحه ظهرت لي نص لرسالة ؛ كشفت عن الخطأ هو رفض الدخول (Access denied)، وتم تعديل حرف كلمة المرور ونجح الاتصال بقاعدة البيانات

  طبعا تم الاستعانه بذكاء الاصطناعي
