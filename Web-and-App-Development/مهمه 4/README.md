



مهمه 4 : انشاء لوحة تحكم بازرار للكلب الربوتي 

مشروع لوحة تحكم تفاعلية لنظام التحكم بالروبوت عبر الإنترنت، يتيح التوجيه باستخدام أزرار الاتجاهات أو عبر الأوامر الصوتية (Speech-to-Text)، مع تخزين الحالات في قاعدة البيانات MySQL ليتسنى للميكروكنترولر (مثل ESP32) قراءتها وتنفذها

شرح المهمه :

**لوحة تحكم للحركة:أزرار توجيه رئيسية (`forward`, `backward`, `left`, `right`, `stop`)
**التحكم الصوتي (Voice Control): تحويل الصوت إلى نص باستخدام تقنية `Web Speech API` وتحويل الكلمات المنطوقة إلى أوامر حركة
**ربط سحابي متكامل: حفظ وتحديث حالة الروبوت فورياً في قاعدة بيانات MySQL على استضافة InfinityFree
**واجهة API للروبوت: ملف `get_state.php` لإرجاع حالة الروبوت الحالية بتنسيق JSON



 الملفات هي :

* `index.html`: واجهة المستخدم ( أزرار التحكم والتعرف على الصوت)
* `db.php`: ملف إعدادات الاتصال بقاعدة البيانات
* `update_command.php`: ملف استقبال الأوامر وتحديث الجدول في قاعدة البيانات
* `get_state.php`: ملف إرجاع الحالة الحالية للروبوت
* `setup.sql`: كود SQL لإنشاء الجدول وإدخال القيم الابتدائية

* رابط المشروع : يقدر اي بتجربته  http://my-robot-control.infinityfreeapp.com/?i=1
  




المشاكل التي واجهتني وكيف تم حلها :


 1. اختيار امتداد النطاق المستقر
  
 المشكلة: ظهور مشكلة في توجيه DNS عند اختيار بعض النطاقات المجانية
 
 الحل: تم الاعتماد على النطاق الرسمي والمستقر `infinityfreeapp.com` لضمان استقرار الاتصال
 

2. حساسيات حالة الأحرف بكلمات المرور
 
 المشكلة:ظهور رسالة "فشل الاتصال بالسيرفر" عند إرسال الأوامر
 
 الحل: مراجعة بيانات الاتصال في `db.php` واكتشاف خطأ في حالة الحرف الأول من كلمة مرور قاعدة البيانات (تعديل الحرف من `F` كبير إلى `f` صغير)

 3. التخزين المؤقت للمتصفح

 المشكلة:عدم استجابة الصفحة للتعديلات البرمجية الجديدة واستمرار ظهور الخطأ القديم

 الحل: تجربة الموقع عبر المتصفح الخفي وتفريغ الذاكرة المؤقتة لاستعراض النسخة المحدثة

تم استعنانه بذكاء الاصطناعي بحل بعض الاشياء
