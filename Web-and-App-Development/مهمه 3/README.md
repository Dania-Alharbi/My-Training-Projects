المهمة 3 : مشروع عملي لربط وإصلاح موقع إلكتروني (تطبيق مساعد صوتي) ؛ الاكواد جهازه نعدل على الاخطاء ونضيف مفتاح 


اسم المشروع: مساعد صوتي 

الوصف:
مشروع شات بوت صوتي يعمل من خلال المتصفح، يسمح للمستخدم بالتحدث باستخدام الميكروفون والحصول على إجابات من نموذج ذكاء اصطناعي. تم استخدام Groq API لمعالجة الطلبات بدلًا من Google Gemin

الملفات ( الاكواد) المستخدمة:

HTML لإنشاء واجهة المستخدم

CSS لتصميم الواجهة

JavaScript للتعرف على الصوت وتحويل النص إلى كلام

PHP كخادم خلفي للتواصل مع API

Groq API كنموذج ذكاء اصطناعي




رابط مشروع للمساعد الصوتي ( الاوت بوت ؛ يستطيع اي احد تجربته) :     https://t-ggg.rf.gd/bot/?i=2

ملفات الحل بتكون 5 وهي : 

1/ app.js 

2/style.Css

3/ ro.php

4/index.html

5/config.php 

ما قدرت أرفع ملف config.php مع كود المفتاح ؛ لأن نظام حماية GitHub حظره تلقائياً بسبب وجود المفتاح السري (API Key)...لذا حذفت كود المفتاح ووضحت في الملف  





المشاكل:

المشكلة في ربط مفتاح APl اما التعديل الكود ما كان فيه مشاكل ،  مفتاح Gemini كان مشكلته ما يشتغل علما انه نسخته صح بس رفض يشتغل قعدت كذا يوم اجرب في مفتاح واغير في نهاية قررت اجيب مفتاح بديل من موقع ثاني

التعديلات اللي سويتها:

1= استبدال Gemini API بـ Groq API

2= تعديل ملف PHP ليتوافق مع طريقة Groq + تعديل اخطاء في الكود 

طبعا تم استعانه في الذكاء الاصطناعي لحل بعض مشكلات 


لاحظت عند استخدام مفتاح (ذكاء الاصطناعي ) لGroq مو مثل جودة مفتاح (ذكاء الاصطناعي ) لGemini
يعني مفتاح Groq فيه اخطاء في الاجوبه مثال : اسم صوت الهره باللغة العربيه هو مواء يقول اللجام طبعا انا ما قدرت استخدم مفتاح لGemini بس شفت مقاطع له في النت كانت دايم اجاباته صحيحه عكسGroq دايم له اخطاء في اجابات
