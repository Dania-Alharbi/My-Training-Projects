المهمة 3 : مشروع عملي لربط وإصلاح موقع إلكتروني (تطبيق مساعد صوتي) ؛ الاكواد جهازه نعدل على الاخطاء ونضيف مفتاح 


اسم المشروع: مساعد صوتي 

الوصف:
مشروع شات بوت صوتي يعمل من خلال المتصفح، يسمح للمستخدم بالتحدث باستخدام الميكروفون والحصول على إجابات من نموذج ذكاء اصطناعي. تم استخدام Groq API لمعالجة الطلبات بدلًا من Google Gemin

الملفات ( الاكواد) المستخدمة:

HTML لإنشاء واجهة المستخدم

CSS لتصميم الواجهة

JavaScript للتعرف على الصوت وتحويل النص إلى كلام

PHP كخادم خلفي للتواصل مع API

Groq API كنموذج ذكاء اصطناعي


رابط مشروع للمساعد الصوتي :     https://t-ggg.rf.gd/bot/?i=2

1/ app.js 

2/style.Css
